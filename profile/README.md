## Platforms

| Platform | Status | Get it |
|---|---|---|
| macOS 13+ | Stable | [Download for Mac](https://tablepro.app/download) or `brew install --cask tablepro` |
| iPhone and iPad (iOS / iPadOS 18+) | Stable; no license needed | [Get TablePro for iPhone and iPad](https://tablepro.app/ios) |
| Linux (amd64 and arm64) | Public beta | [Install guide](https://docs.tablepro.app/linux/install): beta PPA for Ubuntu 26.04/26.10, beta COPR for Fedora 44/45, Flatpak for other distributions |
| Windows | In development; not released | [Source](https://github.com/TableProApp/TablePro/tree/main/windows) |

Linux also has .deb, .rpm and Flatpak bundles on [GitHub Releases](https://github.com/TableProApp/TablePro/releases). Native Linux packages need GNOME 50 libraries; Flatpak provides its own runtime.

## Databases

Query databases and edit data in a native interface. Database support varies by platform: see the [Mac database list](https://tablepro.app/databases) and [Linux connection guide](https://docs.tablepro.app/linux/connect).
