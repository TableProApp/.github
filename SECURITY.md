# Security policy

This policy covers every TableProApp repository that has no SECURITY.md of its own.

## Report a vulnerability

Email **hello@tablepro.app**, or use **Report a vulnerability** on the repository's Security tab. Write in English or Vietnamese.

Do not open a public issue, discussion or pull request for a vulnerability.

Include:

- What is affected and its version: the Mac app, the iPhone and iPad app, a plugin, tablepro.app or the integrations directory.
- The macOS or iOS version, and the database type when a driver is involved.
- Steps to reproduce, or a proof of concept.
- What an attacker gains: the data or access exposed.

## Third-party integrations

Integrations listed in the [integrations directory](https://github.com/TableProApp/integrations) are built by their publishers. Report a vulnerability in one to its publisher. If a listing is malicious or impersonates someone, email hello@tablepro.app.

## Supported versions

Only the latest release of each app and plugin gets security fixes. Check that the problem is still in the latest release before you report it.
