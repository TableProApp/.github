This is the default guide for every TableProApp repository that has no CONTRIBUTING file of its own.

For questions, use [GitHub Discussions](https://github.com/TableProApp/TablePro/discussions) or [Discord](https://discord.gg/hCNmUUbnD4).

## Before you open a pull request

- For anything bigger than a small fix, open an issue or a discussion first.
- One change per pull request.
- Title in [Conventional Commits](https://www.conventionalcommits.org/) form, at most 72 characters: `fix: ...`, `feat(scope): ...`.
- Fill in the pull request template when the repository has one.
- Never report a security problem in an issue or pull request. See [SECURITY.md](https://github.com/TableProApp/.github/blob/main/SECURITY.md).
